# 2048 游戏 - 项目文档

## 🎮 游戏介绍

经典 2048 益智游戏的 Web 版本，使用纯前端技术（HTML/CSS/JavaScript）实现，无需后端服务器。

## 🚀 快速开始

```bash
# 克隆或下载项目后，直接打开
open index.html

# 或使用任意 HTTP 服务器
python -m http.server 8080
# 访问 http://localhost:8080
```

## 🎯 游戏玩法

- 使用 **方向键** 或 **WASD** 控制方块移动
- 相同数字的方块碰撞时会 **合并**
- 目标是合并出 **2048** 或更高的数字
- 支持移动端 **触摸滑动** 操作

## ✨ 功能特性

### v0.1.0 - 核心玩法
- ✅ 4×4 游戏网格
- ✅ 数字方块显示（不同数字不同颜色）
- ✅ 随机生成 2/4（90%/10%概率）
- ✅ 上下左右移动逻辑
- ✅ 相同数字合并
- ✅ 键盘方向键控制
- ✅ 得分系统（合并累加）
- ✅ 游戏开始生成 2 个数字

### v0.2.0 - 游戏体验
- ✅ 数字移动/合并动画
- ✅ 最高分记录（localStorage）
- ✅ 重新开始按钮
- ✅ 游戏结束判定

### v0.3.0 - 增强功能
- ✅ 3×3 / 5×5 / 6×6 网格可选
- ✅ 撤销功能（3次机会）
- ✅ 本地排行榜（每网格前10名）
- ✅ 移动端触摸支持
