# v0.1.0 迭代 - 需求分析任务

## 迭代目标
实现 2048 游戏的核心玩法，让用户能够在浏览器中玩到最基本的游戏功能。

---

## 功能需求清单

### 1. 游戏网格 (Grid)

**需求描述**: 4x4 的游戏网格，共 16 个格子

**验收标准**:
- [ ] 网格清晰可见，格子大小一致
- [ ] 格子之间有明显边界
- [ ] 响应式布局，适配不同屏幕

**技术要点**:
- 使用 CSS Grid 或 Flexbox 布局
- 网格容器固定宽高比 (1:1)

---

### 2. 数字方块 (Tile)

**需求描述**: 显示数字的方块，可移动和合并

**验收标准**:
- [ ] 方块显示数字 (2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048...)
- [ ] 不同数字有不同颜色
- [ ] 数字居中显示

**技术要点**:
- 每个方块是一个 DOM 元素
- 使用 CSS 变量定义颜色主题

---

### 3. 数字生成 (Spawn)

**需求描述**: 每次移动后随机生成新数字

**验收标准**:
- [ ] 在空白格子中随机生成
- [ ] 90% 概率生成 2，10% 概率生成 4
- [ ] 游戏开始时生成 2 个数字

**技术要点**:
- 使用 Math.random() 实现随机
- 记录空白格子列表，随机选择

---

### 4. 移动逻辑 (Move)

**需求描述**: 上下左右移动，数字合并

**验收标准**:
- [ ] 键盘方向键控制移动
- [ ] 所有数字向指定方向移动到边界
- [ ] 相同数字碰撞时合并
- [ ] 一次移动中每个方块只能合并一次
- [ ] 移动后才生成新数字

**技术要点**:
- 核心算法：按方向遍历，处理移动和合并
- 合并后的数字不能再参与当前移动的合并

---

### 5. 得分系统 (Score)

**需求描述**: 记录和显示当前得分

**验收标准**:
- [ ] 合并时累加得分（合并后的数字）
- [ ] 实时显示当前分数
- [ ] 分数显示位置明显

**技术要点**:
- 每次合并 += 合并后的数字值
- 单独的 score 模块管理
